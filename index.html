💡 DSE M1 中央極限定理 (CLT) 考點精要

  • 中央極限定理 (CLT) 原理： 設 X₁, X₂, ..., Xₙ 為獨立同分佈 (i.i.d.) 隨機變量，均值為 μ，方差為 σ²。當 n 相當大（通常 n ≥ 30）時，無論 X 原分佈為何，X̄ ~ N(μ, σ²/n) 近似成立。
  • 泊松與二項分佈實驗： 請切換母體至泊松分佈或二項分佈，觀察當 n = 2 時（極度右偏/不對稱）與當 n = 30 時直方圖形狀的對比！
